# Εξωτερικές διασυνδέσεις: τι υπάρχει, τι χρειάζεται

> Κατάσταση στις 2026-11-08: **καμία** εξωτερική σύνδεση δεν είναι ενεργή. Η εφαρμογή διαβάζει μόνο αρχεία CSV που ανεβάζετε εσείς και δεδομένα που καταχωρείτε χειροκίνητα.
> Τα παρακάτω προέρχονται από τις γνώσεις μου και **δεν τα έχω επαληθεύσει** στις επίσημες σελίδες των παρόχων, γιατί το δίκτυο αυτού του περιβάλλοντος τις μπλοκάρει. Κανένα κόστος ή όρος δεν πρέπει να θεωρηθεί τελικός πριν ελεγχθεί. Θα ενημερώσω το αρχείο μόλις επιτραπεί η πρόσβαση στα αντίστοιχα domains.

## 1. Συγχρονισμός συναλλαγών (brokers)

| Πλατφόρμα | Επίσημος τρόπος | Τι χρειάζεται | Σημειώσεις / ανεπιβεβαίωτα |
|---|---|---|---|
| **Tradovate** | REST + WebSocket API | Λογαριασμός Tradovate, ενεργοποίηση API access, API key/secret (CID/SEC) | Πιθανή μηνιαία χρέωση για API access. Για prop firms που τρέχουν σε Tradovate η πρόσβαση μπορεί να μη δίνεται. **Προς επαλήθευση.** Εναλλακτικά: CSV Performance report, ήδη υλοποιημένο |
| **TradeSea** | Άγνωστο | — | Δεν γνωρίζω δημόσιο API. Χρειάζεται έρευνα ή export αρχείου |
| **NinjaTrader** | Export (Trade Performance → CSV) | — | Χωρίς δημόσιο cloud API για ιστορικό. Τοπικό add-on (NinjaScript) είναι δυνατό |
| **Interactive Brokers** | Flex Web Service (Flex Query + token) | Λογαριασμός IBKR, Flex Query στο Client Portal | Κατά τις γνώσεις μου δωρεάν. **Προς επαλήθευση** |
| **MetaTrader 4/5** | Χωρίς επίσημο cloud API | Τοπικό EA ή Python package (MT5, μόνο Windows) | Εναλλακτικά: export ιστορικού σε HTML/CSV |

Ο κάθε connector θα γραφτεί μόνο αφού δω πραγματική απάντηση του API με τα δικά σας κλειδιά. Τα κλειδιά θα αποθηκεύονται στον server σας, ποτέ στο repository.

## 2. Market data για Replay και Backtesting

| Ανάγκη | Πιθανοί πάροχοι | Σημειώσεις / ανεπιβεβαίωτα |
|---|---|---|
| CME futures (ES, MES, NQ, MNQ…) σε 1 δευτ. ή tick | Databento, Tradovate market data, Rithmic | Πληρωμένα δεδομένα συν τέλη αδειοδότησης του CME. Τα τέλη διαφέρουν για display ή non-display και για professional ή non-professional χρήση. **Κόστος προς επαλήθευση** |
| Μετοχές ΗΠΑ | Polygon (Massive), Alpaca, IEX | Υπάρχουν δωρεάν πακέτα με περιορισμούς και πληρωμένα για πλήρη δεδομένα |

Η μηχανή replay και το chart μπορούν να χτιστούν εδώ. Χρειάζεται πρώτα να αποφασίσουμε πάροχο και να υπάρχει κλειδί.

## 3. AI Analysis

- **API:** Anthropic Messages API, με χρέωση ανά token.
- **Τι χρειάζεται:** δικό σας API key, αποθηκευμένο μόνο στον server σας.
- **Τι στέλνεται:** μόνο συνόψεις συναλλαγών, και screenshots μόνο αν το επιλέξετε.
- **Κατάσταση:** δεν έχει υλοποιηθεί.

## 4. Mentor sharing

- **Τι χρειάζεται:**
  - server προσβάσιμος από το internet (VPS) με HTTPS και domain,
  - login,
  - δικαιώματα ανά λογαριασμό: read-only σύνδεσμοι ή προσκλήσεις,
  - σχόλια ανά συναλλαγή.
- **Κατάσταση:** δεν έχει υλοποιηθεί. Σήμερα ο server ακούει μόνο στο `127.0.0.1` και η εφαρμογή είναι για έναν χρήστη, χωρίς login.

## 5. Πραγματικό κλείδωμα πλατφόρμας (Lock Guard)

Σήμερα οι κανόνες υπολογίζονται και εμφανίζονται στην εφαρμογή, και το endpoint `GET /api/lock-status` επιστρέφει `locked: true/false` ανά λογαριασμό. Για να κλειδώνει πραγματικά η πλατφόρμα χρειάζονται δύο πράγματα:

1. **Δεδομένα σε πραγματικό χρόνο.** Ένα CSV ανεβαίνει μετά το κλείσιμο της ημέρας, οπότε δεν αρκεί. Χρειάζεται API του broker (π.χ. Tradovate) ή ανάγνωση του P&L από την οθόνη. Το δεύτερο είναι αυτό που φαίνεται να κάνει το CHR Lock Guard («teach it your P&L number»).
2. **Desktop helper** στον υπολογιστή σας (Windows/Mac). Θα κλείνει ή θα ελαχιστοποιεί το παράθυρο της πλατφόρμας, ή θα πατά το δικό της κουμπί lock/flatten. Γράφεται, αλλά **δοκιμάζεται μόνο στον δικό σας υπολογιστή** με την πλατφόρμα ανοιχτή.

Ασφαλέστερη εναλλακτική, αν υπάρχει: τα ενσωματωμένα όρια κινδύνου του λογαριασμού σας στην Tradovate ή στην prop firm (daily loss limit, auto-liquidate). **Προς επαλήθευση.**
